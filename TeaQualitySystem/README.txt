# 🍃 TeaTrack: Tea Reception Quality Tracking System

A simple offline desktop app for recording tea leaf deliveries and tracking quality by buying center, truck, and driver.

Built with Python, Tkinter, and SQLite. No internet required.

## 🎯 Why it matters
- Records every delivery and its quality percentage
- Keeps records safe and organized
- Reduces time spent on manual recording
- Makes data accessible across factory departments

## ✨ Features
- 🔐 Login system (Admin & Operator roles)
- 📝 Batch entry with auto-generated Batch IDs
- ⚖️ Two quality methods: Leaf Count & Weight-Based
- 📊 Real-time dashboard
- 📄 Daily & weekly reports
- 🏢 Manage buying centers, trucks, and users
- 💾 Database backup

## 🛠️ Built With
- Python 3.8+
- Tkinter (GUI)
- SQLite 3 (database)
- PyInstaller + Inno Setup (installer)

## 🚀 How to Run
```bash
python tea_system.py
```
